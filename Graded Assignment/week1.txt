Question 1: What will be the values of A, B, C and D after execution of the following
procedure using the “Scores” dataset?

variables A, B, C and D. Let us read the procedure step by step.
      Step 1. Arrange all cards in a single pile called Pile 1
      Step 2. Maintain five variables A, B, C, D, percentage and initialize them to 0
      Step 3. If Pile 1 is empty then stop the execution
      Step 4. Read the top card in Pile 1
      Step 5. Calculate percentage: divide TOTAL marks by 3 and store the result in percentage
In step 5 we are calculating the percentage of a student by diving his/her total marks by 3 and
then the computed result is getting stored in variable percentage.
      Step 6. If percentage ≥ 85 then increment A
      Step 7. If percentage < 85 and percentage ≥ 70 then increment B
      Step 8. If percentage < 70 and percentage ≥ 60 then increment C
      Step 9. If percentage < 60 then increment D
      Step 10. Move the current card to another pile called Pile 2 and repeat from step 3
Here in steps 6 to 9 we are incrementing variables A, B, C and D respectively if the calculated
percentage value lies between the specified range. This same process will be carried out for
all score cards as per the step 10. Based on this observation we can conclude that the given
procedure calculates the student’s percentage and allots him/her a grade as per the performance
in the exams. Therefore, we can find the values of variables A, B, C and D based on how many

nouns, verbs, adjectives and pronouns in the “Paragraph Words” dataset? It is a Multiple

Moving on to next question: What will variable A represent after execution of the following
procedure on the “Paragraph Words” dataset?
      Let us analyse the given procedure, in step 2 two variables A and B are initialized to 0.
In step 5 variable B is getting incremented if part of speech is “Verb” which means variable B
is counting number of verbs. Conditions in steps 6 and 7 are exactly opposite to each other.
As per the combination of steps 6 and 9 we are counting verbs with variable B until we reach
to a full stop. In other words, we are counting number of verbs in each sentence. As per step 7
if a sentence ends and verb count in variable B is 1 then we are incrementing variable A. Step
8 resets the value of variable B so that the same variable can be used to count number of verbs
in the next sentence. Based on this analysis we can conclude that the variable A gets
incremented only if variable B’s value is 1. Hence, the answer of this question is Total number
of sentences with only one verb in it.

Question: The given procedure finds the category which generated the higher revenue between
“electronics” and “stationery” when executed on the “Shopping Bills” dataset. Fill in the
blanks from the given choices and complete the procedure.
       Now, this is a fill in the blanks type of a question where we have to choose the correct
combination of steps from the given options to achieve the procedure’s goal. If we observe the
given options then we can easily notice that the missing steps 2 and 8 corresponds to the
initialization of variables. Variables Ecost and Scost are used to calculate the total cost of items
sold under categories electronics and stationery respectively. Therefore, the initial value of
these variables should be 0 and the correct step 2 should be,
       Step 2. Maintain two variables Ecost, Scost and initialize them to 0
In steps 9 and 10 we are referring to a variable called “higher” which is supposed to store the
category which generated the higher revenue between electronics and stationery. As we all
know electronics and stationery are of type string therefore, the variable higher should be
initialized to “None”.
       Step 8. Maintain a variable higher and initialize it to “None”
Hence the correct answer for this question is:
Step 2. Maintain two variables Ecost, Scost and initialize them to 0
Step 8. Maintain a variable higher and initialize it to “None”
